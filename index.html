Sincronización en la Nube con Google Sheets

Conecta la hoja de cálculo para recibir automáticamente las encuestas que los voluntarios hagan en campo sin señal.

Permite que la app suba las encuestas acumuladas directamente a tu Google Sheet en cuanto el voluntario recupere señal.

Código de Google Apps Script

En tu Google Sheet ve a Extensiones > Apps Script, pega este código y publica como Web App: 

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  if (data.surveys && data.surveys.length > 0) {
    data.surveys.forEach(function(s) {
      sheet.appendRow([
        s.fecha, s.encuestador, s.cedula,
        s.parroquia, s.sector, s.aguaEstado,
        s.aguaProblema, s.aguaObs, s.vialidadEstado,
        s.vialidadProblema, s.vialidadObs, s.lat, s.lng
      ]);
    });
  }
  return ContentService.createTextOutput("OK");
}
¡Cero costos de servidor! Funciona con tu cuenta normal de Google.
Preguntas para tu Google Form:
  1. Parroquia: Menú desplegable (San Simón, Los Godos, Boquerón, etc.)
  2. Sector / Comunidad: Texto breve
  3. Semáforo de Agua: Verde, Amarillo, Rojo
  4. Problema del Agua: Menú desplegable de fallas
  5. Semáforo de Vialidad: Verde, Amarillo, Rojo
  6. Problema de Vialidad: Menú desplegable de fallas
  7. 📍 Ubicación en Google Maps (Opcional): Texto breve (pegar link o coordenadas)
  8. Observaciones: Texto de párrafo
  9. Encuestador / Cédula: Texto breve
